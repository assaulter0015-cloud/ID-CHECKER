ID CHECKER

A tool to check account status using two available versions.

---

1. ID CHECKER OFFLINE V2.1

---

File: ID CHECKER Offline V2.1.zip

Description:
This version checks whether an ID is Active, Inactive, or Disabled.

Requirements:

- User ID
- Password

Features:

- Checks account status using User ID and Password.
- Provides account status information.
- Suitable for checking individual IDs.
- Bulk checking is supported, but execution time depends on the number of IDs being checked.

---

2. ADVANCED CHECKER V1.0

---

File: Available in the Releases section as an EXE.

Description:
Advanced Checker is a faster version designed to check ID status using only a User ID.

Requirements:

- User ID only

Features:

- No password input required.
- Supports checking multiple IDs.
- Optimized for fast execution.
- Can process multiple IDs in approximately 3–5 seconds, depending on conditions.

---

VERSION COMPARISON

ID Checker Offline V2.1:

- Requires User ID and Password.
- Takes more time for bulk checks.

Advanced Checker V1.0:

- Requires only User ID.
- Designed for faster bulk checking.
- Typical reported execution time: 3–5 seconds.

---

IMPORTANT NOTES

- Execution speed may vary depending on network conditions,
  server response times, and the number of IDs.
- Use these tools only with accounts you own or are
  authorized to check.
- Keep your account credentials secure.
